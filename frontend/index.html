这是前端唯一会保存并实际使用的设置。

服务级 `.env`

LOCAL_SOURCE_CONFIG_PATH=config/sources.json
LOCAL_FAISS_INDEX_PATH=data/artifacts/faiss.index
LOCAL_FAISS_DOC_IDS_PATH=data/artifacts/faiss_doc_ids.json
LOCAL_ES_URL=http://127.0.0.1:9200
EMBEDDING_MODEL_PATH=BAAI/bge-small-zh-v1.5
REWRITTEN_QUERY_ES_WEIGHT=1.0

数据源级 `config/sources.json`

每个 source 独立配置 `es_index`、ES/FAISS top-k、融合权重和选择阈值。浏览器不会修改该文件。

评分

base = max(vector_score, es_score_weight × bm25_score_norm)
agreement = agreement_weight × √(vector_score × bm25_score_norm)
confidence = clamp(base + agreement)
selected = confidence ≥ source.selection_threshold
