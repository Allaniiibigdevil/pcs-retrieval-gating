Scoring Reference

评分配置说明

重要：这个页面不会直接修改后端，也不会让配置立即生效。

这里生成的是配置草案。需要手动复制 `.env` 片段到项目根目录的 `.env` 文件中，然后重启后端服务。 已加载的模型、索引和决策引擎实例不会因为浏览器页面变化而自动刷新。

请求

请求规模

默认值：当前页面 origin。通过 FastAPI 静态页面访问时通常不用改。

默认值：50。ES 和 FAISS 各自执行一次全局 Top-K 召回。

融合

RRF 参数

默认值：0.60。FAISS 文档低于该相似度时，在进入 RRF 前删除。

默认值：20。数值越大，列表前后位置的差异越平缓，也越强调双路共同命中。

默认值：10。最终选取的全局 RRF 文档数；这些文档所属的 system 全部进入结果。

公式

当前 RRF 选择逻辑

1. 全局候选 candidates = ES Top-K ∪ FAISS Top-K FAISS candidate 仅在 vector_score >= FAISS_SCORE_THRESHOLD 时保留
2. 文档 RRF rrf(doc) = I(ES)/(RRF_K + es_rank) + I(FAISS)/(RRF_K + vector_rank)
3. 文档截断 selected_docs = global Top RRF_TOP_N_DOCS by rrf(doc)
4. 系统选择 system_rrf = max(rrf(doc) of docs in this system) selected = 该 system 至少有一篇文档进入 selected_docs

核心含义：RRF 只融合两个排序，不直接混合 BM25 和向量分数。system 使用最佳文档，不做多文档求和，也不强制返回固定数量的 system。
