后端

召回规模

默认值：50。仅通过后端 `.env` 配置，ES 和 FAISS 各自执行一次全局 Top-K 召回。

默认值：0.60。优先保留达到该相似度的向量候选。

默认值：0.30。自适应降低阈值时不可越过的安全下限。

默认值：10。优选阈值下数量不足时，逻辑降低阈值以补足向量候选；不会再次请求 FAISS。

精排

GTE Reranker

默认使用项目目录下的 `Alibaba-NLP/gte-multilingual-reranker-base`。

默认值：30。精排的最大文档数；超出时按 ES、FAISS 两路交替保留候选。

默认值：0.50。一个 system 只要有一篇文档达到该值就被选中。

默认值：8。显存或内存充足时可增大以提高批处理吞吐。

默认值：512。摘要更长时可提高，但会增加精排时延和内存占用。

公式

当前 Reranker 选择逻辑

1. 全局候选 E = ES Top-K V_raw = FAISS Top-K where vector_score >= FAISS_MIN_SCORE_THRESHOLD ES 使用 cross_fields；1 个分词须命中 1 个，2 个及以上分词须至少命中 2 个
2. 向量候选自适应 T_eff = T_preferred；不足 N 条时降到第 N 名分数，但不低于 T_min V = {doc in V_raw | vector_score >= T_eff} 整个过程只执行一次 FAISS search
3. Cross-Encoder 精排 C = bounded(E ∪ V, RERANKER_MAX_CANDIDATES) logit(doc) = GTE(query, keywords + summary) reranker_score(doc) = sigmoid(logit(doc))
4. 系统选择 system_score = max(reranker_score(doc) of docs in this system) selected = system_score >= RERANKER_SCORE_THRESHOLD

核心含义：BM25 和向量分数只用于召回与观察，不进入最终加权。GTE 只读取 query、keywords 和 summary，不读取 system_id。system 使用最佳文档，不做多文档求和，也不强制返回固定数量。
