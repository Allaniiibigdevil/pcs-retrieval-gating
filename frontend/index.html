1. 多 query 聚合lexical(d) = max_q ESScore_q(d) / max_x ESScore_q(x)semantic(d) = max_q clamp(VectorScore_q(d), 0, 1)
2. 基础分base = max(semantic, ES_SCORE_WEIGHT * lexical)
3. 一致性奖励agreement = AGREEMENT_WEIGHT * sqrt(semantic * lexical)
4. 文档与系统doc_strength = clamp(base + agreement, 0, 1)system_confidence = max(doc_strength)
