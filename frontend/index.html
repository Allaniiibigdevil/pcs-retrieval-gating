连接

这是前端唯一会保存并实际使用的设置。

服务级 `.env`

LOCAL_SOURCE_CONFIG_PATH=config/sources.json
LOCAL_FAISS_INDEX_PATH=data/artifacts/faiss.index
LOCAL_FAISS_DOC_IDS_PATH=data/artifacts/faiss_doc_ids.json
LOCAL_ES_URL=http://127.0.0.1:9200
EMBEDDING_MODEL_PATH=BAAI/bge-small-zh-v1.5
RERANKER_MODEL_PATH=Alibaba-NLP/gte-multilingual-reranker-base
RERANKER_BATCH_SIZE=8
RERANKER_MAX_LENGTH=512

数据源级 `config/sources.json`

每个 source 独立配置 `es_index`、ES/FAISS top-k、自适应向量候选参数和 reranker 选择阈值。浏览器不会修改该文件。

决策

每个 source 独立粗召回
→ 每源执行向量候选阈值选择
→ 所有候选一次批量 rerank
source_score = max(reranker_score)
selected = source_score ≥ source.reranker_score_threshold
