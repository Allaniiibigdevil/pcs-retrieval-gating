Gating Reference

九元素 Max-MIL 配置说明

重要：这个页面不会直接修改后端，也不会让配置立即生效。

这里生成的是配置草案。需要手动复制 `.env` 片段到项目根目录的 `.env` 文件中，然后重启后端服务。 已加载的模型、索引和决策引擎实例不会因为浏览器页面变化而自动刷新。

请求

请求规模

默认值：当前页面 origin。通过 FastAPI 静态页面访问时通常不用改。

请求字段，默认值：20。ES 和 FAISS 各自召回的候选文档上限。

请求字段，默认值：5。只限制返回的未选中诊断项；所有超过阈值的 system 都会保留。

模型

系统选择与权重文件

默认值：0.60。系统 confidence 大于等于这个阈值时，进入最终的 selected_systems。

完成训练后使用 mil_mlp；没有权重文件时才使用 fixed 采集首批样本。

NPZ 二进制权重路径，包含 MLP 参数、特征 schema 和校准参数。

开启后，未在 query 留出集上完成校准的模型会被拒绝加载。

公式

正式模型决策逻辑

1. 全局候选 candidates = union(ES Top-20, FAISS Top-20)
2. 九元素代表集合 bag(system) = dedupe(ES Top-3 + FAISS Top-3 + RRF Top-3)
3. 内容证据特征 vector / ES 分数与 rank、RRF、双路命中、关键词匹配比例
4. 共享 MLP + Max pooling system_logit = max(MLP(doc_features) for doc in bag)
5. 校准与系统选择 confidence = calibrated_sigmoid(system_logit) selected = confidence >= system_threshold

核心含义：MLP 只读取内容证据特征；system_id 仅负责分 bag、查阈值和输出，不进入模型。
